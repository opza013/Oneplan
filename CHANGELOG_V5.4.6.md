# ONE PLAN v5.4.6

- Added Task Master to Master Data. Admin can add, edit, reorder and delete Task values.
- Task delete is blocked while used by project activities; Task rename updates linked project activities.
- Project Schedule and Detail Plan Task fields are dropdowns sourced from Task Master.
- Sub Task / Phase remains free-form.
- Task Master is included in cache, device-folder state, cloud snapshots, import/export and backups.
- Existing v5.4.5 Task names migrate into Task Master automatically.
- Key Milestone Master color/order and Gantt default sorting are unchanged.
