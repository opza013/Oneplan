# ONE PLAN v5.4.5

## Gantt ordering
- Added Sort by control to the all-project Gantt and Detail Plan project Gantt.
- Default is **Key Milestone Order**.
- Key Milestone Master now has **Display Order**; existing milestone lists are migrated to sequential order automatically.
- Additional sort modes: Task → Sub Task, Planned Start, Live Week, Project Name, Owner.

## Detail Plan structure management
- Added a hierarchical Task → Sub Task → Key Milestone structure section in Detail Plan.
- Add Task (creates its first Sub Task + Key Milestone), Add Sub Task, Add Key Milestone.
- Edit an activity's Task, Sub Task, milestone, dates and status.
- Delete Key Milestone activity, Sub Task, or whole Task with confirmation.
- Project retains at least one activity to preserve schedule integrity.
- Project date range, Gantt, audit history and storage sync update immediately.
