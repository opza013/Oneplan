# OnePlan v5.4.11 — Master Expand View

- Added temporary **Expand / Restore** control to every Master Data card.
- Expanded card uses almost the full browser workspace and keeps its table header sticky.
- Table body expands and scrolls inside the workspace instead of being constrained by the normal card height.
- Click **Restore**, the dimmed background, or press **Esc** to return to the aligned Master layout.
- Expanded state is retained across Master Data edits/rerenders during the current session, but is not persisted to storage.
- No changes to project data, Task/NWT/Milestone masters, storage schema, or multi-PIC behavior.
