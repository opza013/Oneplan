# OnePlan v5.4.13 — Master Data Layout Order

- Expanded Master Data cards now use an X-only close control instead of Restore.
- Master Data layout reordered:
  1. Key Milestone Master — full-width top row.
  2. Event Type Master / Task Master / NWT Master — same row.
  3. Store Master / Capacity Model — same row.
  4. Role Permissions — full-width bottom row.
- Cards in the same row use governed equal heights and internal scrolling.
- Existing Event Type, Task, NWT, Multi-PIC, Gantt, Detail Plan and storage logic are unchanged.
