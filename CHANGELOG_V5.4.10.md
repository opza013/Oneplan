# v5.4.10 — Key Milestone Multi-PIC Responsibility

- NWT Master is now the source list for PIC / Responsible Units assigned in Key Milestone Master.
- Each Key Milestone supports multiple PIC units with Add / Remove controls.
- Key Milestone Master table shows all assigned PIC units.
- Detail Plan inherits PIC units from the selected Key Milestone.
- Responsible person names remain free-form per PIC unit and per activity.
- Changing a Key Milestone PIC setup automatically synchronizes linked project activities while preserving matching responsible names.
- NWT rename updates Key Milestone assignments and activity responsibility rows.
- NWT delete is blocked while assigned to any Key Milestone.
- Existing single NWT/PIC activity data migrates automatically into the new responsibility array.
