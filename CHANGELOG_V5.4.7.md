# ONE PLAN v5.4.7 — NWT Master & Activity Responsibility

- Added NWT Master for responsible unit/team maintenance.
- Admin can add, edit, reorder and delete NWT values; delete is blocked while in use.
- Renaming an NWT updates linked project activities.
- Every Task → Sub Task → Key Milestone activity now stores an NWT / Responsible Unit selected from Master Data.
- PIC / Responsible Person remains free-form per activity in Detail Plan and Project editor.
- Detail Plan structure and Activity Next Steps show NWT and PIC.
- Existing projects migrate automatically with default NWT assignment by milestone; no reset required.
- NWT Master is included in local cache, device-folder state, cloud state and JSON export.
